🚀 Anleitung: Duckiebot ROS 1 Entwicklungsumgebung (HTML-Final)

Diese Anleitung richtet die komplette C++-Umgebung mithilfe von VS Code Dev Containers ein.

1. ⚙️ Voraussetzungen

  1. VS Code und Docker Desktop (oder Docker Engine) installieren.
  2. (WICHTIG für C++!) Installiere im VS Code Marktplatz diese Erweiterungen: Dev Containers, C/C++ Extension Pack.

2. 🖥️ Projekt im Container starten

  1. Ordner öffnen und Fehler ignorieren: Öffne den Ordner ros-actuator-wheels in VS Code. IGNORIERE den anfänglichen Fehler “Could not find Catkin/OpenCV” – dieser verschwindet, sobald der Container startet.

  2. Code holen: Git klonen und auf den richtigen Zweig wechseln. WICHTIG: Ersetze https://github.com/MH-Oliver/lane-detection-duckiebot.git durch die korrekte Adresse!

    git clone [https://github.com/MH-Oliver/lane-detection-duckiebot.git](https://github.com/MH-Oliver/lane-detection-duckiebot.git)
cd lane-detection-duckiebot/ros-actuator-wheels
git checkout dev-container-setup

  3. Container starten: Drücke F1 und wähle Dev Containers: Reopen in Container.

3. ✅ Workspace und Bauen

  • Manuelle Workspace-Auswahl (WICHTIG!)

    • Drücke F1. Wähle: CMake: Select a Kit ([Unspecified]).
    • Drücke F1. Wähle: CMake: Select active folder (example_ros_wheels).

  • Projekt bauen: Führe im Terminal aus:

    catkin_make

  • C++-Erkennung aktualisieren:

    • Nach 100% erfolgreichem Build:
    • Drücke F1 und wähle Developer: Reload Window.

4. 🔄 Entwicklungs-Workflow (Testen von Änderungen)

Nachdem das Projekt einmal gebaut wurde, ist das Testen einfach.

  1. Code ändern: Bearbeite eine Deiner .cpp-Dateien in VS Code und speichere sie.

  2. Neu kompilieren: Führe im Terminal (Terminal 2 oder einem beliebigen anderen Terminal im /ws-Ordner) nur den catkin_make Befehl aus: root@82569905ba07:/ws# catkin_make

  3. Programm neu starten:

    • Beende das laufende Programm (rosrun...) in Terminal 2 mit Strg + C.
    • Starte das Programm neu:
    rosrun example_ros_wheels driver_cpp_node

5. 🏃 Code ausführen (Erster Start)

  1. Terminal 1 (Der Manager): Starte roscore. Lasse dieses Terminal geöffnet.

    roscore

  2. Terminal 2 (Dein Programm): Öffne ein zweites Terminal.

    source devel/setup.bash
rosrun example_ros_wheels driver_cpp_node

6. 🛑 Container schließen

  • Um den Container zu schließen und zu beenden, klicke unten links in VS Code auf das grüne >< Symbol.
  • Wähle Close Remote Connection.

Wichtig: Beim nächsten Start musst Du nur Schritt 2 und dann Schritt 3 (ohne Rebuild) wiederholen.
